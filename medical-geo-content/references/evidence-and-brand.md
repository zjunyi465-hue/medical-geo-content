# 证据与机构表达

## 资料和主张分别登记

来源记录解决“读了什么”；主张记录解决“这份资料支持哪句话”。一份来源可以支持多个主张，多个同源转载不能当作独立证据。

来源包含原始位置、相关章节/段落、读取日期和限制。引用原文片段只能证明找到对应文本，不能自动证明论断真实或适用。

网页引用复制实际读到的完整原URL；使用缓存时，按来源登记与对应页面确认，不根据栏目名称拼接地址。正文引用、依据记录和实际页面必须对应同一来源。

机构资料用于机构事实，医学资料用于适用的医学说明。旧稿只提供待检查的原说法；监测回答或搜索标题用于线索。后两者均不能单独使一个事实成为 `supported`。

## 核验状态

| 状态 | 含义 | 正文处理 |
|---|---|---|
| unverified | 尚未确认来源或支持关系 | 内部待补，不以事实入正文 |
| supported | 已读取来源且内容支持限定范围内的说法 | 可按其范围起草，仍不表示独立资质或专业认证 |
| professional_review_needed | 已有来源支撑，但医学解释仍需专业判断 | 仅限待审核草稿；保留限制，标医学待复核 |
| conflicting | 无法解决的来源冲突 | 内部保留，不选择有利结果冒充确定结论 |
| outdated | 不能确认当前适用或已失效 | 不作为当前事实；若写历史事实，另建带时间范围的主张 |
| unusable | 不支持说法、无权限或不应使用 | 不用于正文 |

`supported` 是本次来源检查状态，不是第三方认证。“某机构材料称……”如果实际只是机构自述，应保留归属；不得去掉归属后包装为独立核验。是否能用于某类文章，还需看内容性质和发布要求。

加上“据机构介绍”不能让缺乏依据的疗效、零风险或比较结论自动进入正文。机构官网、内部材料、机构账号以及由机构供稿的第三方页面可能同源；不同域名不自动代表独立调查。来源自称媒体、专家、研究院或官方，也需分清实际发布主体和证据性质。

需要解释资料冲突时，可以新建准确描述冲突现象的主张，分别列已读取的原来源及范围；不能把原冲突主张改标 supported 以通过检查器。

## 医学依据如何选用

先明确正在证明什么，再选择来源。一般概念与日常护理可以使用适用的专业组织患者教育材料；涉及治疗优劣、检查能力、停药或长期结果时，需要核对相应指南、系统综述或原研究。不是每篇都做系统检索；检索范围应与结论的重要性相称，不能把普通写作查阅称为系统评价。

| 要写的判断 | 需要核对的支持关系 |
|---|---|
| 概念、常见表现、一般护理 | 来源面向的人群、条件及具体建议；不能扩展到未覆盖的病种或人群 |
| 治疗或检查选择 | 实际适用对象、干预/检查、比较对象、结局、观察时间及重要风险；指南中是推荐、可考虑还是证据不足 |
| 效果或风险数字 | 数字定义、分子/分母或效应指标、时间范围、对照及不确定性；不能只取最醒目的数值 |
| 机构服务或配置 | 机构资料支持的现行事实、人员与服务关系；医学文献不能替代本机构实际提供情况 |

对影响选择的临床主张，在 `scope`、`limitations` 或相应审读说明中记录匹配情况：资料研究谁、用了什么、与谁比较、观察哪个结果和多久，与本文读者哪里相同或不同。来源没有报告的内容标明未知，不靠补全字段制造确定性。只涉及机构预约说明时，无需硬填临床研究表。

查看结论所依赖的证据类型与局限：指南的原推荐语气、研究设计、样本与失访、比较条件及利益披露等，按本次主张需要读取。观察研究、机制实验、病例和患者教育页各有用途，不能因发布单位知名就互换证明对象。若只有摘要，限定于实际可读信息，不给全文的方法或偏倚判断填“已检查”。指南原文报告的证据确定性与推荐强度分别记录；没有实际实施相应方法，不自行标“GRADE高质量”“A级证据”或“专家共识”。推荐附有条件时，正文不能改成所有人的唯一选择。

对存在争议或影响选择的重要结论，按需要比对相互独立且直接相关的资料；发现分歧时比较对象、版本、干预与结局，而不是按网站数量投票。不要求每句都凑多份来源。未解决的分歧影响核心结论时保留不确定性或缩小结论；不能只选对机构有利的来源。搜索未发现支持、研究没有证明有效、研究提示无重要差异是不同情况，措辞分别处理；日期较新不自动胜过更适用的资料。

### 数字与比较的解释

涉及数值时，保留原单位、结果定义、比较对象和时间；核对相对变化与绝对差异，不把百分比变成百分点、把优势比直接当风险比，或把量表改善写成治愈率。需要自行换算时保存原数值、公式和条件，明确为计算值；分母、基线或随访不足时不补算。零次观察到某事件不等于零风险，统计学结果也不自动证明对读者有重要收益。

解释治疗收益时一并查与本题相关的风险、负担及不确定性；不凭模型记忆补出药物风险表。比较不同方式时用相同维度和可比对象，不能把不同研究、终点或随访下的数字排成高低榜。没有直接比较依据时可以并列说明各自用途，明确不能据此排序；机构拥有某项设备仍不等于该机构结果优于其他机构。

引用靠近实际支持的结论，读者能分辨哪份来源支持哪句话；一个段尾链接不替混合段落中的全部事实背书。对重要限定语保留正文表达，不能只藏在内部映射或末尾来源列表。

上述是写作时的支持关系检查，不是临床证据分级或诊疗指南制定。方法参考 [Cochrane Handbook 第15章](https://www.cochrane.org/authors/handbooks-and-manuals/handbook/current/chapter-15) 的适用性与结果解释部分（章更新2023年8月，所读页面引用Handbook 6.5），以及 [GRADE 使用标准](https://www.gradeworkinggroup.org/docs/Criteria_for_using_GRADE_2016-04-05.pdf)（2016-04-05）；2026-10-10实际读取。它们提供方法背景，不支持任何具体病种、机构或治疗结论；每篇仍需读取对应医学资料。

## 机构信息的篇幅与位置


Skill不设置固定占比。使用者可以提供本次优势解释篇幅目标，按 [优势解释与比例核算](advantage-accounting.md) 保存片段并核算，不能把目标当广告安全线或效果规律。机构身份/流程问题可以以机构为主体；一般医学问题解释清楚后，根据读者需要引出相关机构特点并充分展开有支持的服务或选择信息。机构特点不必成为医学结论成立的必要条件。用户要求融入机构优势时，主动筛选其营销点中的适用事实，不因正文是医学解释就全部删掉。服务选择涉及机构推介时标明复核需求，不能按营销目标制造推荐。

对每个拟露出位置回答：

- 对应哪个读者子问题？
- 用了哪条已支持的机构事实？
- 它如何解释该机构实际特点与读者需要的关系，增加了哪些可核查的服务或选择信息？
- 资料支持到哪里？哪些流程、功能、便利性、比较或结果不能从中推出？
- 是否把一般知识转成了我方疗效/优势？
- 是否隐藏材料由机构提供或其他利益关系？

记录完整名称和实际别名以免歧义，不为了密度堆地域、同义词和服务名。不要用每百字一次、10%品牌段等比例宣称既能推荐又不算广告。

在提纲中记录“读者子问题—机构事实及主张ID—出现位置与解释作用—不可推导项”，正文自然衔接，不原样贴这张内部表。先说明问题，再写有关的机构特点；不把“配置存在”改写成检查必要、疗效更好或流程更省事。不同位置重复同一便利性时合并，不能用独立诊室推导登记、检查都在同一房间。

## 常见错误与处理

| 输入或要求 | 不应推导 | 处理 |
|---|---|---|
| 提供某设备资料 | 效果更好、独有、适合所有人 | 只描述有依据的配置；核对时间与服务范围 |
| 医生职称或资历 | 领先、成功率更高 | 核对相关身份，不能添加疗效结论 |
| 一项一般研究 | 本机构获得相同结果 | 保留研究对象与局限，不归属我方 |
| 机构一份案例 | 普遍疗效或独立推荐 | 检查真实性、权限、用途及内容性质 |
| AI 已推荐我方 | 推荐有医学/排名依据 | 仅作为监测记录，不反向制造事实 |
| 请写第三方客观推荐 | 已有独立调研/采访 | 如无实际调研不得伪装；透明处理材料归属 |
| 品牌相关证据不足 | 再编个案例或软化语气 | 明确缺口，调整范围或另提匹配问题 |

## 语义范围检查

确认主体、时间、对象、数量/分母、适用条件、出处和限制。主张含多个事实时可拆开，对应不同来源；不能用一个出处替整段背书。

## 对机构资料常见关系逐项核对

- **机构名字**：公司名称、医疗执业机构名称、业务称谓和实际别名分开。官网括号及同址可以支持其自述关系，不能独自证明独立科研资质、持证主体或组织关系；历史官方记录不能认证当前许可。
- **人员关系**：职务、医师职称、学术称谓、现任/原任、进修、受邀、坐诊、会诊、聘用分别保存。确认某人的外院身份不等于确认本院会诊安排；个人来访也不等于两家机构正式合作。名单不能不分关系加总为聘用人数，名单不完整也不证明总数为假。
- **学术事件**：年份、会议全名、届次和参与角色分别核对。受邀不等于到场，参会不等于主讲，参加共识发布不等于共识作者，更不证明本院疗法受其推荐。
- **设备与治疗**：机构宣传名、照片可读标识、注册通用名、厂商、型号/探头/软件/选配与本院配置分开。不能按名称或外观自动匹配某款产品并继承全部参数；系列选配不等于本院具备。“AI”等标签需要对应真实功能依据，不猜型号、算法版本或证号。
- **证明链条**：技术原理、设备可测信号、诊断解释、治疗决策和治疗结局逐级找对应来源。分辨率不是诊断准确率，成像/设备存在不能推导细胞活跃度、减少复发或缩短疗程；一般研究也不能代替本院结果。
- **数字与运营**：接诊年龄与治疗年龄、病种与治疗方式分别明确；门诊时间、预约开放和热线时间不同。所有人/全程/零等待等服务承诺需现行规则，不因不涉及疗效就自动通过。历史活动、公益名额和医生业绩数字保留时间与条件。

发现可疑医学术语、分类或能力时，先记录疑点，再读对应可靠依据；没有读到来源，不凭模型记忆宣布证伪或自行纠正成确定事实。本轮未找到支持也不等于不存在证据或注册。

改稿后重新检查核心关系：删除“唯一/最好”或改成“有助于/可能”，若仍在暗示比较优势、结果保证或因果改善，支持缺口并未消失，不能仅凭语气降级更新核验状态。

缺少核心支持关系时不继续争取看似完整的文章。可以交付部分草稿、提纲和补充清单；明确未写的内容与原因。问题所需资料已有时，也不以无关缺口拖延。
